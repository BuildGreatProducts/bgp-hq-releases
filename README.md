# BGP HQ releases

Downloads and the auto-update feed for **BGP HQ**, the Mac app the Build Great Products team runs the business from.

- **Download:** the `.dmg` on the [latest release](https://github.com/BuildGreatProducts/bgp-hq-releases/releases/latest). It's signed and notarised, for Macs with Apple silicon or Intel.
- **Sign-in is invite-only.** You need an invite from Chris to use it.
- Installed apps update themselves from this page.

This repo holds only the built app. The source code is private.
